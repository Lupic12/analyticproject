# Тест-кейсы

Тест-кейс — набор действий и ожидаемый результат для проверки функции.

| ID | Проверка | Действия | Ожидаемый результат |
|---|---|---|---|
| TC-01 | Оформление заказа | Выбрать товар с достаточным остатком и подтвердить заказ. | Заказ сохранён, присвоен номер. |
| TC-02 | Недостаток товара | Попытаться заказать больше, чем есть на складе. | Система сообщает о нехватке. |
| TC-03 | Статус заказа | Менеджер меняет статус. | Новый статус сохранён. |
| TC-04 | Остатки | Склад меняет количество товара. | Количество сохранено; отрицательное значение отклоняется. |
| TC-05 | Оплата | Открыть заказ и проверить сумму и статус. | Данные отображаются корректно. |
| TC-06 | Доставка | Курьер меняет статус своей доставки. | Статус сохранён. |
| TC-07 | Доступ покупателя | Покупатель открывает список заказов. | Видны только его заказы. |
| TC-08 | Отчёт | Владелец выбирает период и открывает отчёт. | Показаны число заказов и сумма продаж. |
