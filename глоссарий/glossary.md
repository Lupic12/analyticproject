# Глоссарий

| Термин | Объяснение простыми словами |
|---|---|
| ТЗ | Техническое задание — описание того, что должна делать система. |
| Требование | Функция или условие, которое система должна выполнять. |
| User Story | Что пользователь хочет сделать и зачем. |
| Use Case | Сценарий взаимодействия пользователя с системой. |
| Критерии приёмки | Условия, по которым проверяют правильность функции. |
| ER-диаграмма | Схема сущностей, данных и связей между ними. |
| DFD | Диаграмма движения информации. |
| PK | Первичный ключ — уникальный номер записи. |
| FK | Внешний ключ — поле, связывающее таблицы. |
| Кардинальность | Показывает, сколько записей одной сущности связано с другой, например 1:M. |
| CRUD | Создать, просмотреть, изменить, удалить. |
| RTM | Матрица трассировки, связывающая требования с историями и проверками. |
| Wiki | Общая база знаний проекта. |
| Тест-кейс | Инструкция для проверки функции. |
