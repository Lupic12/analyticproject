# Ролевая модель

| Роль | Задачи |
|---|---|
| Покупатель | Создаёт заказ, просматривает свои заказы, оплату и доставку. |
| Менеджер | Обрабатывает заказы, проверяет оплату, меняет статусы. |
| Складской сотрудник | Работает с товарами и остатками. |
| Курьер | Видит назначенные доставки и обновляет статусы. |
| Владелец | Контролирует работу и просматривает отчёты. |
| Разработчик | Настраивает и исправляет программную часть в пределах прав. |
| Аналитик | Изучает процессы, требования и результаты работы системы. |
