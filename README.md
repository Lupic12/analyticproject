# ИТ-база знаний проекта

**Проект:** информационная система учёта и обработки заказов интернет-магазина.

## Обзор

Цель проекта — объединить сведения о заказах, покупателях, товарах, оплатах и доставках, уменьшить ручную работу и количество ошибок.

Основные функции:
- оформление и обработка заказов;
- проверка остатков товаров;
- учёт оплат;
- управление доставками;
- формирование отчётов;
- разграничение доступа по ролям.
