# ИТ-база знаний проекта

## Информационная система учёта и обработки заказов интернет-магазина

### Обзор проекта

**Цель проекта:** разработка информационной системы для учёта и обработки заказов интернет-магазина.

Система предназначена для объединения информации о покупателях, товарах, заказах, оплатах и доставках, сокращения ручной работы и уменьшения количества ошибок.

**Основные функции:**
- Оформление и обработка заказов.
- Учёт товаров и контроль остатков.
- Учёт оплат.
- Управление доставками.
- Формирование отчётов.
- Разграничение доступа пользователей.
