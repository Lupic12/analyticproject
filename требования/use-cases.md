# Use Cases

## Use Case 1. Оформление заказа

| Поле | Описание |
|---|---|
| Актор | Покупатель |
| Цель | Создать заказ на выбранные товары. |
| Предусловие | Товары доступны для заказа. |
| Основной сценарий | 1. Покупатель выбирает товары. 2. Указывает количество. 3. Система проверяет остатки. 4. Покупатель подтверждает заказ. 5. Система сохраняет заказ и присваивает номер. |
| Альтернативный сценарий | Если товара недостаточно, система сообщает об этом и предлагает изменить количество. |
| Результат | Заказ сохранён и готов к обработке. |

## Use Case 2. Обработка заказа

| Поле | Описание |
|---|---|
| Актор | Менеджер |
| Цель | Проверить заказ и обновить его статус. |
| Предусловие | Заказ создан, менеджер вошёл в систему. |
| Основной сценарий | 1. Менеджер открывает список. 2. Выбирает заказ. 3. Проверяет товары и оплату. 4. Меняет статус. 5. Система сохраняет изменения. |
| Альтернативный сценарий | Если данные требуют уточнения, менеджер уточняет их до перехода к следующему этапу. |
| Результат | В системе отображается актуальный статус. |
