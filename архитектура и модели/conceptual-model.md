# Концептуальная схема

Покупатель создаёт заказ; заказ включает товары; менеджер обрабатывает заказ; оплата связана с заказом; доставка назначается курьеру; владелец использует данные для отчётов.

| Понятие | Описание |
|---|---|
| Покупатель | Человек, оформляющий заказ. |
| Заказ | Запись о покупке, дате, сумме и статусе. |
| Товар | Позиция каталога с названием, ценой и остатком. |
| Состав заказа | Связывает заказ и товар; хранит количество и цену на момент покупки. |
| Сотрудник | Например, менеджер или курьер. |
| Оплата | Сумма, способ, дата и статус оплаты. |
| Доставка | Адрес, дата, статус и назначенный курьер. |
