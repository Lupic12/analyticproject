# ER-диаграмма — сущности и связи

ER-диаграмма показывает структуру данных. PK — первичный ключ, FK — внешний ключ.

## Сущности и основные поля

| Сущность | Основные поля |
|---|---|
| Покупатель | PK `id_покупателя`; ФИО; телефон; email; адрес |
| Заказ | PK `id_заказа`; FK `id_покупателя`; FK `id_менеджера`; дата; статус; сумма |
| Сотрудник | PK `id_сотрудника`; ФИО; должность; телефон |
| Товар | PK `id_товара`; название; цена; остаток |
| Состав заказа | PK `id_позиции`; FK `id_заказа`; FK `id_товара`; количество; цена |
| Оплата | PK `id_оплаты`; FK `id_заказа`; сумма; способ; статус; дата |
| Доставка | PK `id_доставки`; FK `id_заказа`; FK `id_курьера`; адрес; дата; статус |

## Связи

| Связь | Кардинальность | Объяснение |
|---|---|---|
| Покупатель — Заказ | 1:M | У покупателя может быть много заказов; каждый заказ принадлежит одному покупателю. |
| Сотрудник — Заказ | 1:M | Менеджер может обработать много заказов; у заказа назначен менеджер. |
| Заказ — Состав заказа | 1:M | Заказ включает несколько товарных позиций. |
| Товар — Состав заказа | 1:M | Товар может встречаться во многих заказах. |
| Заказ — Оплата | 1:0..1 | Заказ может быть ещё не оплачен или иметь одну запись об оплате. |
| Заказ — Доставка | 1:0..1 | Доставка может ещё не быть создана или быть одна. |
| Сотрудник (курьер) — Доставка | 1:M | Курьер может выполнить много доставок; у доставки один курьер. |

Заказ и товар связаны через «Состав заказа», так как один заказ содержит несколько товаров, а один товар может входить в разные заказы.
