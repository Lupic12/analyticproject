# DFD — диаграмма потоков данных

DFD показывает, откуда приходят данные, какие процессы их обрабатывают, где они хранятся и кому передаются результаты.

## Внешние сущности

| Внешняя сущность | Что передаёт / получает |
|---|---|
| Покупатель | Передаёт данные заказа; получает номер и статус. |
| Менеджер | Получает список заказов; меняет статусы. |
| Склад | Проверяет и обновляет остатки. |
| Курьер | Получает данные доставки; передаёт новый статус. |
| Владелец | Получает отчёты. |

## Процессы

| № | Процесс | Вход | Результат |
|---|---|---|---|
| 1 | Приём заказа | Товары и данные покупателя | Новый заказ |
| 2 | Обработка заказа | Данные заказа | Обновлённый статус |
| 3 | Проверка наличия | Товары и количество | Подтверждение наличия или сообщение о нехватке |
| 4 | Учёт оплаты | Данные оплаты | Статус оплаты |
| 5 | Организация доставки | Заказ, адрес, курьер | Данные доставки и её статус |
| 6 | Формирование отчёта | Заказы и продажи | Отчёт владельцу |

## Хранилища данных

| Код | Хранилище данных |
|---|---|
| D1 | База заказов |
| D2 | База товаров и остатков |
| D3 | База покупателей |
| D4 | База оплат |
| D5 | База доставок |

**Пример потока:** Покупатель → данные заказа → «Приём заказа» → D1 «База заказов» → список заказов для менеджера.

Это текстовое описание DFD. Графическую схему можно добавить отдельно после согласования её вида.
